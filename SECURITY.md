# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TAQA KnowledgeHub, do not open a public issue.

Report it directly to the TAQA Learning Center platform owner, or to TAQA Cybersecurity through the standard internal reporting channel.

Include:
- A description of the issue
- Steps to reproduce it
- The page or file affected

Reports are acknowledged within two working days.

## Scope

This platform is an internal TAQA application. It is not open to external contributors and is not intended for public use.

## Supported Versions

Only the current version deployed from the `main` branch is supported.
