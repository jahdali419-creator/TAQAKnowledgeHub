1Purpose and scope

This manual sets out how the injector head is rigged up, operated and rigged down on Coiled Tubing units.

It applies to every CT crew and supervisor running the unit, onshore and offshore.

2References

TQ-TWS-CTSS-SOP-002 Coiled Tubing Rig-Up.

TQ-TWS-CTSS-S001 CT Operations Authorization Standard.

Manufacturer’s injector head manual for the unit in use.

3Safety

Safety

Keep clear of the gooseneck and chains while the injector is moving.

Stop the job if traction pressure goes above the limit in section 4.2 and call the supervisor.

4Pre-job checks

Check chain condition, gripper blocks and lubrication before rig-up.

Record the checks on F001 Pre-Job Safety Checklist.

4.2Traction pressure limitsChanged in Rev 4.0

For 2-inch string the traction pressure limit is set out in table 4.2. Do not run above it.

Set the relief valve to the table value before running in hole, and record the setting.

5Operating the injector head

Run in hole at the speeds in table 5.1, reducing speed through restrictions.

Watch weight and traction pressure together. A rise in one without the other means stop and check.

6Emergency stop and disconnect

Use the emergency stop on the console first. Follow SOP-004 Emergency Disconnect if the string must be released.

7Records

Keep the completed checklist and job log with the job file for 10 years.

Uncontrolled when printed. Check the current revision in RISE before use.
