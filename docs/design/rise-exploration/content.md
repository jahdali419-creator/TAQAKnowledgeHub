## Upload (the submission flow)
Three steps: 1 Select file → 2 Document details → 3 Review & submit. One file = one document.
Show the REVIEW step for:
- File: CT-Acid-Stimulation-Rev4.pdf (2.4 MB)
- Kind: Revision of an existing document → TQ-TWS-CTSS-SOP-009 Acid Stimulation SOP, Rev 3.0 → **Rev 4.0** (same number, D1 rule)
- Area: Coiled Tubing · Side: Operations · Type: SOP · Classification: Internal · Language: English · Audience: Field Operators
- Change note: "Updated HCl concentration limits and added a neutralisation hold point."
- Routing (the final approver must be shown clearly): Filed by you → QMS check (QMS Document Control) → **Final approval: Segment Director, Coiled Tubing** → Current. Rev 3.0 is superseded when Rev 4.0 is approved; its Arabic translation (SOP-009-AR) is flagged "to be re-issued".
- Maintenance documents route instead: QMS check → Maintenance Manager, <segment>.
- Separation of duties note: the person who files can't do the QMS check or the final approval.
