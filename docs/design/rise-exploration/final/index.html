Where we can enhance

In the order I would take them.

  1. Finish the two screens that still look half-converted

    The Director’s own Home and the three “not part of your role” pages only got a thin dark bar. Give them the full photo top like every other screen.

  2. Arabic, right to left

    Every screen is English only. RISE serves Arabic readers and keeps Arabic copies of documents, so the key screens (Home, Search, Document, an area) need an Arabic version with Somar type and mirrored layout.

  3. One navigation everywhere

    Home, the area pages and the family pages use a slightly different top bar from the rest (“Ask” vs “Ask an Expert”, search button missing). Make it one bar with the same links in the same order.

  4. Reading a document on site

    The document page shows a “preview not connected” box. Design the real reader: page view, jump to a section, “what changed in this revision” highlighted, and readable in sunlight.

  5. Loading, offline and error states

    Show what a screen looks like while it loads, when the phone has no signal, and when the register cannot be reached, in the new style.

  6. Real photos for the support functions

    HR, Finance, IT, Legal, Supply Chain, Commercial and Aberdeen still use stand-in pictures.

  7. Use the full 21st components

    The command search and spotlight cards were rebuilt by hand from their descriptions. Swap in the real 21st code once the daily download limit allows.

  8. Accessibility check

    Check text contrast on the toned photos, keyboard order in Search and Upload, and every screen with motion turned off.
