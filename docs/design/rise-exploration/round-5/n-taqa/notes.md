# N + TAQA — direction N rebuilt on the TAQA UI/UX skill

Demonstration only. Original N is untouched in `../n/`; no winner is declared. Before/after page: `../taqa-skill.html`.

## Why N
RISE is a controlled-document system for field and operations users. The skill ranks safety first, then
procedure, then concept; N already leads with identity, status, revision and the ALT-002 change, so the
skill's rules reinforce it.

## Rules applied
- Colours: Teal Green #00585A (structure, primary actions, active tab), Legacy Teal #00BFB2 (highlight),
  Alpine family #007A6B for "Current", Crimson #C8102E for safety only, Orange #FF6720 only as the
  notification spark (≤5%).
- Safety Warning callout for ALT-002 (it changes WI-003 §5 operating limits): 4px Crimson rule on #FFF5F5.
- BW Gradual for headings and body; Inter kept only as fallback.
- Filled two-tone icons (solid shape + 32% tint) replace the outline set; status symbols unchanged.
- Arabic Home (`home-ar.html`) in Somar, `dir="rtl"`: rail, timeline, callout rule and counters mirror;
  codes, revisions and §5 stay left-to-right. Somar files added to `../../kit/fonts/`.

## Not applied, and why
- E-learning limits (60–80 words, Next/Back, progress bar): RISE is a register, not a training module.
- Monument Gray #968C83 as body text: ~3.3:1 on white, fails WCAG AA; used for nothing here.
- Brand values conflict: skill #00585A/#FF6720 vs kit #005D63/#FD691D. Confirm against the official
  TAQA Brand Guidelines before any build.
