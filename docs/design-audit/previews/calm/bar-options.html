Search bar — style options

Same icon, same label, same width in every option. Only the bar's own style changes, so what you are comparing is the style and nothing else. Each one is shown at rest on the real white panel, then focused and with text typed.

The reason the text looks big: the field is set to font: 500 16.5px and the placeholder inherits both. So the grey prompt is rendered at body size in medium weight, which is why an empty bar reads like a filled one.

What every option below does: the placeholder is sized separately from the field — 14px grey for the prompt, 16px for anything you actually type. You get the small quiet prompt you asked for without shrinking real text.

Why typed text stays at 16px: iOS Safari zooms the whole page in when you focus a field whose font-size is under 16px. Shrinking the input itself would make every search on an iPhone jump the layout. Sizing only the placeholder avoids that completely.
