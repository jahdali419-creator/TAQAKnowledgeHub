3Numbering follows TQ-QHSE-S001 5.3

The Hub was inventing its own scheme, and two of its prefixes collided with short forms the standard had already assigned elsewhere.

WasNowWhy it mattered
CT-001TQ-TWS-CTSS-SOP-001Business unit, service line and type are all carried in the number.
WS-001TQ-TWS-WSS-SOP-001Collision. The Hub used WS for Well Safety. The standard assigns WS to Wireline Services.
CS-PROC-001TQ-CYB-SOP-001Collision. The Hub used CS for Cybersecurity. The standard assigns CS to Customer Service.
ALERT-CT-001TQ-TWS-CTSS-ALT-001Technical Alert is not a type defined in section 4, so no conformant code exists.

4Who can see and control the register

Role decides which functions you get. Classification decides which documents. The register itself stays readable by everyone, because restricting it would breach 5.5, and a supervisor needs to confirm the current revision before starting a job.

Set it to Employee. The overdue queue, the numbering report and the export all disappear, and 200 documents leave the register.

This is not security

Role switching runs in the browser and proves nothing. It is a specification. The back end applies the same rules on the server, from an Entra ID group through the SSO claim to a check on every record.
