# TechHub (TAQA Knowledge Hub)

Internal document-control and field-knowledge portal for TAQA. Static frontend prototype; Azure integration (Entra ID, API, database, file storage, notifications) is being handed over to IT.

- **Start here:** [`docs/HANDOVER-TO-IT.md`](docs/HANDOVER-TO-IT.md)
- Run locally: `npm ci && npm run serve`, then open http://127.0.0.1:4173
- Test: [`docs/TESTING.md`](docs/TESTING.md)

Maintained by the TAQA Learning Center. Platform owner: Learning Center. Security reports: [`SECURITY.md`](SECURITY.md).
