# TechHub (TAQA Knowledge Hub)

Internal document-control and field-knowledge portal for TAQA. Static frontend prototype and product specification (RISE). It is not production and not production-secure. SCORE remains the system of record. The production design on Microsoft 365 / Azure is being handed over to IT, who own the architecture.

- **Start here:** [`docs/handover/README.md`](docs/handover/README.md) (IT handover pack) and [`docs/RISE-BUSINESS-DECISIONS.md`](docs/RISE-BUSINESS-DECISIONS.md) (the owner's decisions)
- Run locally: `npm ci && npm run serve`, then open http://127.0.0.1:4173
- Test: [`docs/TESTING.md`](docs/TESTING.md)

Maintained by the TAQA Learning Center. Platform owner: Learning Center. Security reports: [`SECURITY.md`](SECURITY.md).
