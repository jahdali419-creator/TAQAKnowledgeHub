About the data

Titles for the twelve original segments are real. The fourteen areas added with the new entity model carry representative titles, because no documents have been filed against them yet. Revision, approval, review and status values are generated throughout so the controls can be seen working. The schema is what matters: it sets the fields the back end supplies.

Owner and approver hold roles, not names. Role switching runs in the browser and proves nothing about access. The server has to apply the same rules.
