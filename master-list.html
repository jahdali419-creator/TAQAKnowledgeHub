TQ-QHSE-S001 §5.1 · ISO 9001:2015 §7.5 · API Spec Q2 3rd Ed. §4.4, §4.5
Viewing as Prototype data Read the caveats

Prototype. The document titles are real. Revision, approval, review and status values are generated so the controls can be seen working. The schema is what matters: it sets out the fields the back end has to supply. Owner and approver hold roles rather than personal names, which is what API Q2 §4.4.3 a) asks for and keeps personal data out of the register.

Switching role here runs in the browser and proves nothing about access. The back end has to apply the same matrix on the server, from an Entra ID group through the SSO claim to a check on every record.
