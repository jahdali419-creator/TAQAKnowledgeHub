      How a case reaches the library

      1. Operations file it: an employee, or the area’s Director.
      2. QMS checks it against its source document.
      3. The area’s Director releases it. Only then is it listed here.

      Until it is released, only its filer, QMS, the area’s Director and an external auditor can see it. Lessons learned and technical alerts that are register documents are listed too, marked Register.
